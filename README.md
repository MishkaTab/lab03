# Лабораторная работа № 3. Каталог транспортных маршрутов

Пакет на Python 3.13 для хранения транспортных маршрутов. Позволяет добавлять и удалять маршруты, искать их по ID, названию и категории, а также сохранять каталог в JSON и загружать данные из файла.

## Маршрут и каталог

`Route` — класс маршрута. Он хранит строковый ID, название, категорию, дату, начальную и конечную остановки. При создании проверяются типы полей и дата. Дата в будущем вызывает ошибку `WrongRoute`.

`Catalog` хранит маршруты в словаре с ключами по ID. Добавление маршрута с занятым ID вызывает `DuplicateId`. Поиск по названию работает без учёта регистра. При обходе каталога маршруты выдаются в порядке добавления.

## Работа с JSON

В корне файла находятся номер версии `format_version` и список маршрутов `items`. Даты записываются в формате `ДД.ММ.ГГГГ`. Пример данных — в [routes.json](src/transport_routes/routes.json).

При загрузке маршруты сначала проверяются во временном каталоге. Если весь файл прочитан успешно, новые маршруты добавляются в основной каталог. Если ID уже есть в основном каталоге, сохраняется прежняя запись. При ошибке чтения или проверки файла основной каталог остаётся без изменений.

## Структура проекта

- `src/transport_routes/models.py` — классы `Route` и `Catalog`.
- `src/transport_routes/errors.py` — исключения каталога.
- `src/transport_routes/load_to_json.py` — сохранение маршрутов в JSON.
- `src/transport_routes/read_json.py` — чтение JSON и слияние каталогов.
- `tests/` — тесты модели, каталога и работы с JSON.

## Запуск тестов

Из корня проекта на macOS или Linux:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install "pytest>=8.3.5,<9"
python -m pytest -q
```

Если окружение уже активировано и pytest установлен, достаточно последней команды.
